# Big Band Chamber Concerts

Website der **Big Band Chamber Concerts** – einer Konzertreihe für Bigbands und Jazzorchester aus Mannheim und der Rhein-Neckar-Region.

Kuratiert von **Jochen Welsch** bringt die Reihe unterschiedliche Ensembles, Programme und musikalische Handschriften auf die Bühne und macht die Vielfalt der regionalen Bigband-Szene aus nächster Nähe erlebbar.

### Website

[bigbandchamberconcerts.de](https://bigbandchamberconcerts.de/)

### Über dieses Repository

Dieses Repository enthält die statische Website der Big Band Chamber Concerts sowie die Seiten vergangener Spielzeiten.

Die Website ist bewusst schlank umgesetzt und basiert auf HTML, CSS und JavaScript.
